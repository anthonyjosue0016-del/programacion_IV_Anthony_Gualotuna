# Programación IV

**Autor:** Anthony Gualotuña

## Objetivo principal

La materia de **Programación IV** tiene como objetivo principal aprender y aplicar los fundamentos del **desarrollo de aplicaciones móviles**, utilizando diferentes tecnologías y herramientas que permitan crear aplicaciones funcionales, organizadas y adaptadas a dispositivos móviles.

Durante la materia se busca fortalecer los conocimientos de programación mediante el desarrollo de proyectos móviles, trabajando tanto la interfaz de usuario como la lógica de las aplicaciones.

## Tecnologías

### Android

Plataforma utilizada para el desarrollo de aplicaciones móviles. Permite crear aplicaciones para dispositivos que utilizan el sistema operativo Android.

### Kotlin

Lenguaje de programación utilizado principalmente para el desarrollo de aplicaciones Android. Se caracteriza por tener una sintaxis sencilla y moderna.

### Java

Lenguaje de programación utilizado tradicionalmente en el desarrollo de aplicaciones Android. Permite trabajar con la lógica y diferentes funcionalidades de las aplicaciones.

### Android Studio

Entorno de desarrollo integrado (IDE) utilizado para crear, ejecutar y probar aplicaciones móviles para Android. Permite trabajar con el código, diseño de interfaces y herramientas de prueba.

### XML

Lenguaje utilizado para definir y organizar diferentes elementos de la interfaz gráfica en aplicaciones Android, como botones, textos, imágenes y otros componentes.

### Git y GitHub

**Git** es un sistema de control de versiones que permite registrar y administrar los cambios realizados en un proyecto.

**GitHub** es una plataforma que permite almacenar repositorios y trabajar de manera colaborativa, facilitando el seguimiento y organización de los proyectos.
